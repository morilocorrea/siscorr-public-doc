Rastro SRO

Política de Privacidade

Esta política de privacidade descreve como o aplicativo Rastro SRO lida com suas informações. Nosso compromisso é com a transparência e a segurança dos seus dados.

1. Informações que Coletamos

O Rastro SRO coleta e utiliza informações para fornecer um serviço de rastreamento de objetos eficiente. As informações podem incluir:

  • Códigos de Rastreamento: Fornecidos manualmente pelo usuário para consulta junto aos serviços postais.
  • Informações de Uso: Dados anônimos sobre como o aplicativo é utilizado, para fins de melhoria contínua.
  • Identificadores de Dispositivo: Utilizados por serviços de publicidade (AdMob) para exibir anúncios relevantes.

2. Permissões do Dispositivo

Para o funcionamento pleno de todas as ferramentas, o aplicativo pode solicitar as seguintes permissões:

  • Câmera: Necessária exclusivamente para a funcionalidade de leitura de códigos de barras.
  • Armazenamento: Utilizada para salvar e compartilhar capturas de tela (screenshots) dos rastreios, conforme solicitação do usuário.
  • Contatos/Contas: Permissão opcional para permitir a sincronização de dados com o Google Drive.
  • Notificações: Para alertar o usuário sobre atualizações no status dos objetos rastreados.

3. Serviços de Terceiros

O aplicativo utiliza serviços de parceiros que possuem suas próprias políticas de privacidade:

  • Google Play Services: Para funcionalidades base do sistema Android.
  • AdMob: Para exibição de anúncios.
  • Google Drive API: Caso o usuário opte por realizar backup em nuvem de seus dados de rastreio.

4. Segurança dos Dados

Seus dados de rastreio são armazenados localmente no seu dispositivo. Caso você utilize a sincronização com o Google Drive, os dados serão transferidos de forma segura para sua conta pessoal, e o desenvolvedor não tem acesso a esses arquivos.

5. Alterações nesta Política

Podemos atualizar nossa Política de Privacidade de tempos em tempos. Recomendamos que você revise esta página periodicamente para quaisquer alterações.
